1. field vs property trong C#
- Field: là một biến được khai báo trực tiếp trong một lớp hoặc struct, có thể có phạm vi truy cập khác nhau (public, private, protected, internal). Field thường được sử dụng để lưu trữ dữ liệu nội bộ của một lớp hoặc struct và có thể được truy cập trực tiếp từ bên ngoài nếu có phạm vi truy cập phù hợp. Ví dụ:
```csharp
public class Person
{
    public string Name; // Đây là một field
}
```
- Property: là một thành phần của một lớp hoặc struct, cung cấp một cách để truy    cập và thiết lập giá trị của một trường (field) thông qua các phương thức getter và setter. Property thường được sử dụng để kiểm soát việc truy cập và thay đổi dữ liệu, cho phép bạn thực hiện các hành động bổ sung khi giá trị được truy cập hoặc thay đổi. Ví dụ:
```csharppublic class Person
{
    private string name; // Đây là một field
    public string Name // Đây là một property
    {
        get { return name; }
        set { name = value; }
    }
}```
- Sự khác biệt chính giữa field và property là field là một biến trực tiếp, trong khi property là một phương thức truy cập và thiết lập giá trị của một field. Property cung cấp một cách để kiểm soát việc truy cập và thay đổi dữ liệu, trong khi field chỉ là một biến đơn giản. Sử dụng property giúp tăng tính bảo mật và kiểm soát hơn khi làm việc với dữ liệu trong một lớp hoặc struct.
